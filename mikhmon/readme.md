# MikroTik Hotspot Monitoring Open Source • GPLv2 • Educational & 
Custom UI Edition 

Pengembangan dan kustomisasi **Mikhmon V3 WS** beserta template **Hotspot Landing Page** untuk mempermudah manajemen voucher, monitoring perangkat jaringan (Access Point/Netwatch), dan halaman isolir/login pelanggan MikroTik.
